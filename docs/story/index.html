Chapter 3 · the prompt

I described it in one prompt.

The actual prompt · Feb 2026

"This is a cricket cards Trump game app. Players log in, select online / CPU / friends, pick a format — Test, T20 or IPL — and each is dealt 15 cards, categorised into batsmen, bowlers and all-rounders…"

↳ Plain English. Every mode, rule and number — decided in words first, and it kept evolving. The detail in the prompt is the product.

Chapter 5 · the data

Real stats become the card numbers.

A cricket card needs real numbers. The Cricbuzz API serves each player's career; the backend maps it onto the card and stores it in MongoDB — refreshed automatically as new matches finish.

📡 Cricbuzz APIplayer career — Test / ODI / T20 / IPL
